# Use a Snapshot and Watch Manager Interface

The central Go Manager Module exposes `Snapshot`, `Watch`, and `Close` as its external Interface. CLI, TUI, and desktop IPC are Adapters over that Seam; coalesced Snapshots leave it. Persistent intent (Forwarding Policies, default host) lives in versioned JSONC files, not on this Interface. A per-host actor remains hidden in the Implementation, while true-external OpenSSH and deterministic reconnect use private internal Seams. This hybrid was chosen over exposing the actor mailbox or a broad resource-method tree because it gives callers a small, discoverable Interface without leaking reconciliation steps.
