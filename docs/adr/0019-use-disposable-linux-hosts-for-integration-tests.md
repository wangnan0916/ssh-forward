# Use disposable Linux hosts for integration tests

Local and CI integration tests will use the same pinned, disposable Ubuntu container with a real OpenSSH server, unprivileged test user, Linux process interfaces, and isolated ephemeral SSH material. The harness requires Docker Engine 28 or newer through a local Unix socket, gives concurrent runs separate projects and keys, and rejects SSH host/config overrides. Automated tests must not resolve or connect to a configured Development Host; real-host testing requires a separate explicit user authorization. This provides deterministic coverage of the scanner, SOCKS transport, TCP behavior, and disconnect lifecycle without risking active development workloads, while macOS-specific behavior remains covered on macOS runners and absolute performance budgets remain gated on the reference Mac.
