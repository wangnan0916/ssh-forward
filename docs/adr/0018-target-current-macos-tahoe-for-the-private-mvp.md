# Target the current macOS Tahoe machine for the private MVP

The private MVP will target the developer's current Apple Silicon macOS Tahoe 26.6.1 machine and a Linux Development Host, without claiming support for older macOS, Intel, Linux-local, or Windows-local operation. The Go domain remains isolated from platform Adapters, but untestable platform implementations are deferred. This prioritizes rapid self-use validation over a compatibility matrix that cannot yet be exercised.
